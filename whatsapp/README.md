# CureMindset — חיבור וואטסאפ 🟢

בוט שעונה לאנשים **בוואטסאפ** אוטומטית, באמצעות אותו "מוח" של האתר
(שיטת קטי + עקרונות NLP). החיבור בשיטת **QR (WhatsApp Web)** — כמו המעקף
של Base44, אבל בנוי כאן בקוד שלנו, בלי תלות בשום פלטפורמה חיצונית.

## איך זה עובד
```
אדם כותב בוואטסאפ  →  bot.js (מחובר דרך QR)  →  POST /api/wa/reply בשרת שלנו
                                                   →  המוח (GPT / מנוע NLP מקומי)
                                                   →  תשובה חוזרת לוואטסאפ
```
- `bot.js` — מתחבר לוואטסאפ (Baileys), מקבל הודעות, ושולח תשובות.
- `/api/wa/reply` (ב-`server/index.js`) — ה"מוח". נתיב נפרד שלא נוגע באזור האישי/אתר.

## הרצה מקומית (לבדיקה)
```bash
cd whatsapp
npm install
WA_BOT_SECRET="<אותו סוד כמו בשרת>" \
BRAIN_URL="https://curemindsetheraphy.onrender.com" \
npm start
```
בפעם הראשונה יודפס **QR** בטרמינל. סורקים אותו פעם אחת:
> וואטסאפ בטלפון → **הגדרות** → **מכשירים מקושרים** → **קישור מכשיר** → סריקה

אחרי סריקה אחת החיבור נשמר ב-`auth/` וממשיך לבד.

## הרצה בענן (שתמשיך לעבוד 24/7)
צריך תהליך **שרץ תמיד** עם אחסון קבוע ל-`auth/`:
- **Render → Background Worker** על תיקיית `whatsapp/`, עם **Persistent Disk**
  ממופה ל-`auth/` (כדי שלא תצטרכי לסרוק QR שוב בכל הפעלה).
- משתני סביבה: `WA_BOT_SECRET` (זהה לשרת), `BRAIN_URL`, `AUTH_DIR=/data/auth`.

## משתני סביבה
| משתנה | ברירת מחדל | למה |
|---|---|---|
| `WA_BOT_SECRET` | (ריק) | סוד משותף שמאמת את הבוט מול השרת. חובה בפרודקשן. |
| `BRAIN_URL` | `https://curemindsetheraphy.onrender.com` | כתובת השרת עם ה"מוח". |
| `AUTH_DIR` | `./auth` | איפה נשמר חיבור הוואטסאפ. בענן — דיסק קבוע. |

## ⚠️ חשוב לדעת
- זו שיטה **לא-רשמית** של וואטסאפ. מומלץ **מספר ייעודי לבוט**, לא המספר הראשי —
  וואטסאפ עלול להגביל/לחסום מספר שמזוהה כפעילות אוטומטית.
- `auth/` מכיל את פרטי החיבור לוואטסאפ — **לעולם לא להעלות אותו ל-Git** (כבר ב-`.gitignore`).
- ללא `WA_BOT_SECRET` כל אחד יוכל לפנות ל-`/api/wa/reply`. בפרודקשן — חובה להגדיר.
