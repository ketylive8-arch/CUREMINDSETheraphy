# Segev MKG · מערכת לידים — מפרט

מערכת עצמאית לניהול לידים ושליחה עבור **Segev MKG** (העסק של סוכני ה-AI).
נפרדת לחלוטין מאתר CureMindset — יושבת בתיקייה `lead-system/` משלה, עם דאטהבייס,
התחברות ומשתמשים משלה. **אסור לערבב בין המערכת הזו לאתר.**

## 1. מה המערכת עושה (בשפה פשוטה)
1. מחזיקה את כל הלידים העסקיים במקום אחד, עם סטטוס לכל אחד.
2. מראה מה **נשלח**, מה **חזר** (bounce) ועם איזו סיבה, ומי **לא ענה**.
3. לכל מייל שחזר — כפתור **לאתר כתובת חדשה** ולשלוח שוב.
4. למי שלא ענה — מפיקה **מייל אחרון** (טיוטה) לאישור.
5. כל פעולה נרשמת ב**יומן פעילות** — רואים הכל בתוך המערכת, לא בצ'אט.
6. **כניסה מאובטחת**, ואפשר **לחבר עוד משתמשים** שמקבלים קוד גישה.

## 2. ארכיטקטורה
| שכבה | טכנולוגיה |
|------|-----------|
| צד לקוח (UI) | **React** (RTL עברית, פלטת Segev — זהב/קרם) |
| צד שרת (API) | **PHP 8.3**, REST, `/api/*` |
| דאטהבייס | **SQLite** כברירת מחדל (PDO) · מוכן ל-MySQL (משנים `DB_DSN`) |
| אבטחה | סיסמאות `bcrypt`, טוקן סשן, Prepared Statements, הגבלת ניסיונות, כותרות אבטחה + CSP |
| שליחה | SMTP (מקור שליחה) — פעיל כשמגדירים פרטי segevmkg |

## 3. מסכים
- **כניסה** — אימייל + סיסמה.
- **לוח בקרה** — אריחי סטטוס (סה״כ / נשלחו / חזרו / ללא מענה / ענו) + טבלת לידים עם סינון וחיפוש.
- **חזרו** — רשימת כל ה-bounce עם הסיבה וכפתור איתור מייל חדש.
- **יומן פעילות** — כל הפעולות שבוצעו.
- **משתמשים** (מנהלת בלבד) — יצירת משתמש + קוד גישה.

## 4. סטטוסים של ליד
`חדש` → `נשלח` → (`חזר` / `ללא מענה` / `ענו`). ביניים: `בתור שליחה`, `מאתר מייל`, `הוסר`.

## 5. מסד הנתונים (טבלאות)
- `users` — משתמשים (שם, אימייל, hash סיסמה, תפקיד, קוד גישה).
- `sessions` — טוקני התחברות עם תוקף.
- `login_attempts` — להגבלת קצב.
- `leads` — החברה, מייל, תחום, עיר, אתר, סטטוס, סיבת bounce, תאריך שליחה/מענה, הערות.
- `activity` — יומן כל הפעולות.

## 6. נקודות קצה (API)
```
POST /api/login            כניסה
POST /api/logout           יציאה
GET  /api/me               מי מחובר
GET  /api/stats            מונים ללוח הבקרה
GET  /api/leads?status&q   רשימת לידים (סינון/חיפוש)
GET  /api/bounces          רשימת החזרות
GET  /api/activity         יומן פעילות
POST /api/leads/{id}/refind    התחלת איתור מייל חדש
POST /api/leads/{id}/email     שמירת מייל מאומת חדש
POST /api/leads/{id}/resend    הכנסה לתור שליחה
POST /api/leads/{id}/followup  הפקת "מייל אחרון"
GET  /api/users                משתמשים (מנהלת)
POST /api/users                יצירת משתמש + קוד
```

**בזהות segevmkg בלבד**, עד `DAILY_SEND_CAP` ליום, ורק אחרי אישור.
